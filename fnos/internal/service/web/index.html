容器与虚拟机接入
  1. 记录客户端原 IPv4 / IPv6 网关和 DNS，确认 NAS 与客户端相互可达。
  2. 普通 Docker host / bridge 先验证现有网络，不要重复登记网关网段。
  3. 需要经 NAS 路由的客户端，按所选模式分别调整网关。macvlan、ipvlan、网卡直通不标记自动支持。
  4. 分别验证 TCP、UDP、DNS、NAS 管理页、SMB、容器互访与发布端口。
  5. 停用应用、卸载或关闭 NAS 前，恢复这些客户端的原网关。
高级设置：网关客户端

只登记明确的私有客户端网段，不修改客户端网关。仅 IPv4 模式不接受 IPv6 网段。

高级设置：故障检测地址

规则模式检测首页的主要策略组，全局模式检测 GLOBAL。连续三次失败撤销接管，两次恢复后重试；单组结果不代表所有分流目标。

恢复工具

关闭代理并撤销本应用的接管与普通转发。请先恢复网关客户端原网关，避免客户端断网。不会清空系统防火墙或 Docker 规则。
